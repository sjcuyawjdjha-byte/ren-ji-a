# 视频背景音乐切换器

一个纯前端实现的视频背景音乐自由切换工具。在播放视频的同时，通过侧边栏交互面板随意切换背景音乐，支持音量调节、静音控制和淡入淡出过渡效果。

无需任何构建工具，浏览器打开即可使用。

---

## 功能特性

- **音乐列表切换** — 侧边栏展示所有曲目，点击即可切换
- **淡入淡出过渡** — 切换音乐时自动淡出旧曲目、淡入新曲目，过渡流畅
- **播放/暂停** — 点击正在播放的曲目可暂停，再点恢复
- **音量滑块** — 实时拖动调节背景音乐音量（0%~100%）
- **静音按钮** — 一键静音/恢复，保留之前的音量位置
- **视频联动** — 视频暂停时音乐自动暂停，视频播放时音乐自动恢复
- **自动循环** — 音乐播完后自动重头播放，无需手动操作
- **响应式布局** — 桌面端左右排列，移动端自动切换为上下排列

## 如何上传自己的视频和音频

### 第一步：准备素材文件夹

在项目根目录下创建 `video` 和 `music` 两个文件夹，将你的文件放进去：

```
ren-ji-a/
├── video/
│   └── my-video.mp4          ← 你的视频文件
├── music/
│   ├── song1.mp3             ← 背景音乐1
│   ├── song2.mp3             ← 背景音乐2
│   └── song3.mp3             ← 背景音乐3
├── index.html
├── style.css
└── app.js
```

### 第二步：修改视频路径

打开 `index.html`，找到第 16 行的 `<source>` 标签，将 `src` 改为你的视频文件路径。

**修改前：**
```html
<source src="video/sample-video.mp4" type="video/mp4">
```

**修改后：**
```html
<source src="video/my-video.mp4" type="video/mp4">
```

> 将 `my-video.mp4` 替换为你实际的视频文件名。

### 第三步：修改音乐列表

打开 `app.js`，编辑文件顶部的 `musicList` 数组。每一行代表一首曲目：

**修改前（默认占位符）：**
```js
const musicList = [
  { name: '宁静钢琴',   src: 'music/calm-piano.mp3' },
  { name: '电子节拍',   src: 'music/electronic-beat.mp3' },
  { name: '木吉他',     src: 'music/acoustic-guitar.mp3' },
  { name: '氛围音浪',   src: 'music/ambient-waves.mp3' },
  { name: '爵士酒廊',   src: 'music/jazz-lounge.mp3' },
];
```

**修改后（替换为你自己的音乐）：**
```js
const musicList = [
  { name: '我的歌曲1', src: 'music/song1.mp3' },
  { name: '我的歌曲2', src: 'music/song2.mp3' },
  { name: '我的歌曲3', src: 'music/song3.mp3' },
];
```

**说明：**
- `name` — 在侧边栏中显示的曲目名称，随意填写
- `src` — 音乐文件的路径，对应 `music/` 文件夹中的文件名
- 数量不限，想加几首都可以，也可以只留一首

**想增加一首？** 在数组中添加一行：
```js
  { name: '新歌曲', src: 'music/new-song.mp3' },
```

**想删除一首？** 直接删掉对应的那一行即可。

### 第四步：启动本地服务器

由于浏览器安全限制，直接双击打开 `index.html`（`file://` 协议）可能无法播放音频。需要通过本地服务器访问：

**方式一：Python（最简单，无需安装）**
```bash
cd ren-ji-a
python3 -m http.server 8080
```
然后浏览器打开 `http://localhost:8080`

**方式二：VS Code Live Server 插件**
1. 在 VS Code 中安装 "Live Server" 插件
2. 右键点击 `index.html` → "Open with Live Server"

**方式三：Node.js**
```bash
npx serve .
```

## 交互操作说明

| 操作 | 效果 |
|------|------|
| 点击侧边栏中的曲目 | 切换到该背景音乐（带淡入淡出过渡） |
| 再次点击正在播放的曲目 | 暂停该曲目（图标变为 ⏸） |
| 再点一次暂停的曲目 | 恢复播放（图标变为 ▶） |
| 拖动音量滑块 | 实时调节背景音乐音量（0%~100%） |
| 点击 🔊 按钮 | 静音（变为 🔇），再点恢复原音量 |
| 暂停视频 | 背景音乐自动同步暂停 |
| 播放视频 | 背景音乐自动同步恢复 |

## 支持的文件格式

| 类型 | 推荐格式 | 其他支持格式 |
|------|----------|-------------|
| 视频 | MP4 | WebM、OGG |
| 音乐 | MP3 | WAV、OGG、AAC |

> 推荐使用 MP4 视频和 MP3 音乐，兼容性最好。

---

## 视频与音乐时长不匹配？

不用担心，项目已自动处理：

| 情况 | 自动行为 |
|------|----------|
| 音乐比视频短 | 音乐自动循环播放，直到视频结束 |
| 音乐比视频长 | 视频结束时，音乐同步暂停 |
| 时长相同 | 正好同步结束 |
